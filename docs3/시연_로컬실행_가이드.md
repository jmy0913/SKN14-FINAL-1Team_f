# 로컬 시연 실행 가이드 (ai 서버 + web 서버)

## 0. 구조 요약

| 서버 | 위치 | 프레임워크 | 포트 | 역할 |
|------|------|-----------|------|------|
| **web** | `web/` | Django | **8000** | 웹 UI + `apichat`(GPT-4o, 하이브리드 RAG) + `internal`(sLLM 호출) |
| **ai** | `ai/` | FastAPI/uvicorn | **8001** | sLLM(Qwen3) 챗봇. vLLM 엔드포인트로 프록시 |

- `web → ai` 호출: `internal/utils/sllm.py` 가 `SLLM_API_URL + /api/v1/chat` 로 POST
- `ai → vLLM`: `langchain_service.py` 가 `VLLM_API_URL`(OpenAI 호환)로 호출
- 두 서버 모두 **첫 실행 시 Chroma 벡터DB를 Google Drive에서 자동 다운로드**(gdown), 임베딩 `BAAI/bge-m3`(~2GB)도 최초 1회 다운로드 → 첫 기동이 느림

---

## 1. ai 서버 — `ai/.env`

```dotenv
# vLLM(OpenAI 호환) 엔드포인트 — Qwen3 파인튜닝 모델 서빙 중인 주소
VLLM_API_URL=http://<vllm-host>:8000/v1
VLLM_MODEL=<서빙중인 모델명>      # 예: Qwen3-8B-codenova
VLLM_API_KEY=EMPTY               # vLLM은 보통 아무 값이나 허용 (빈 인증)
```

> ⚠️ **핵심 의존성**: ai 서버는 `VLLM_API_URL` 이 없으면 import 단계에서 바로 죽습니다.
> GPU/vLLM이 없다면 임시로 OpenAI를 꽂아도 동작합니다:
> `VLLM_API_URL=https://api.openai.com/v1`, `VLLM_MODEL=gpt-4o-mini`, `VLLM_API_KEY=<OpenAI 키>`

### 실행 (PowerShell)
```powershell
cd ai
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py        # uvicorn 0.0.0.0:8001 (reload)
# 확인: http://127.0.0.1:8001/health , http://127.0.0.1:8001/docs
```

## 2. web 서버 — `web/.env`

```dotenv
# --- DB (MySQL 필수) ---
MYSQL_DATABASE=codenovadb
MYSQL_USER=django
MYSQL_PASSWORD=django
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306

# --- apichat (GPT-4o RAG 챗봇) ---
OPENAI_API_KEY=sk-...            # 필수
OPENAI_TITLE_MODEL=gpt-4o-mini   # 선택(기본 gpt-4o-mini)
OPENAI_SUGGEST_MODEL=gpt-4o-mini # 선택

# --- internal (sLLM 챗봇) → ai 서버 주소 ---
SLLM_API_URL=http://127.0.0.1:8001

# --- AWS S3 (프로필/첨부 이미지 업로드 기능에만 사용. 챗봇 데모엔 불필요) ---
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_STORAGE_BUCKET_NAME=
AWS_STORAGE_BUCKET_NAME2=
AWS_S3_REGION_NAME=ap-northeast-2
```

> - `SLLM_API_URL` 도 없으면 `internal` 앱 import 시 죽습니다 → ai 서버 주소 꼭 채우기.
> - S3 값은 비워둬도 챗봇 시연은 됩니다. 단 **프로필 이미지 변경/이미지 첨부**를 시연하려면 채워야 함.
> - `SECRET_KEY`/`DEBUG`/`ALLOWED_HOSTS` 는 settings.py에 개발용으로 하드코딩되어 있어 `.env` 불필요.

### 실행 (PowerShell)
```powershell
# (사전) MySQL 기동 + DB 생성: CREATE DATABASE codenovadb CHARACTER SET utf8mb4;
cd web
python -m venv .venv; .\.venv\Scripts\Activate.ps1
pip install -r requirements-prod.txt
python manage.py migrate
python manage.py createsuperuser   # 선택: 로그인 계정
python manage.py runserver 0.0.0.0:8000
# 접속: http://127.0.0.1:8000
```

## 3. 시연 체크리스트

1. MySQL 켜져 있고 `codenovadb` 존재 + `migrate` 완료
2. `ai` 서버(8001) 먼저 기동 → `/health` 200 확인
3. `web` 서버(8000) 기동 → 로그인
4. **apichat 챗봇**(GPT-4o): `OPENAI_API_KEY` 만 있으면 동작
5. **internal 챗봇**(sLLM): `ai` 서버 + vLLM 엔드포인트가 살아 있어야 동작
6. 첫 질문은 벡터DB/임베딩 다운로드로 느릴 수 있음 — 시연 전 워밍업 1회 권장

## 자주 막히는 곳
- `VLLM_API_URL`/`SLLM_API_URL` 누락 → 서버가 import 단계에서 즉시 종료
- vLLM(GPU) 미준비 → internal 챗봇만 실패. 임시로 OpenAI로 대체 가능(위 1번 참고)
- `mysqlclient` 설치 실패(Windows) → MySQL Connector/C 또는 빌드도구 필요
- 첫 실행 시 gdown 드라이브 다운로드가 권한/네트워크로 실패하면 챗봇 검색이 빔
