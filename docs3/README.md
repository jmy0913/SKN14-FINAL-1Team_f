# RAG 평가 핵심 정리 (면접용)

> `docs2/`의 방대한 RAG 실험 중, **면접에서 바로 보여줄 수 있는 핵심 평가 5가지**만 압축했습니다.
> 각 실험은 "왜 이 선택을 했는가"를 **정량 근거**로 증명합니다.

## 30초 요약

- **목적**: 사내 기술문서(Google Cloud/Firestore 등) 기반 사내 RAG 챗봇의 검색·생성 품질을 정량 검증
- **스택**: `BAAI/bge-m3` 임베딩 · Chroma(Dense) + BM25(Sparse) **하이브리드 검색** · LangGraph 오케스트레이션 · GPT-4o/4.1 · 일부 sLLM(Qwen3-8B) 파인튜닝
- **평가 방법**: ① 정답 라벨 기반 **검색 지표**(P@K·R@K·MRR·MAP) ② **RAGAS**(context recall / faithfulness / factual correctness) ③ **LLM-as-Judge**(1~5점)
- **결론**: 하이브리드 검색 + QA 인덱싱 + 파이프라인 반복 개선으로 **상용 Perplexity 대비 정확도 90 vs 80.6** 달성

| # | 실험 | 핵심 결과 | 증명한 것 |
|---|------|-----------|-----------|
| 1 | 검색기 비교 (160 쿼리) | Weighted RRF가 전 지표 1위 (MRR 0.55) | **하이브리드 검색** 채택 근거 |
| 2 | 청킹 전략 (RAGAS) | QA 인덱싱 recall 0.75→0.85, 정확성 0.44→0.63 | **QA 기반 인덱싱** 채택 근거 |
| 3 | top_k 튜닝 | 검색 k 조정으로 충분성 4.6→4.7 | **검색 깊이** 최적화 |
| 4 | 파이프라인 9버전 반복 | 종합점수 9.55 → **12.70 / 15** | **반복 개선** 효과 |
| 5 | vs Perplexity (18 쿼리) | 정확도 **90 vs 80.6**, 재현율 92.8 vs 82.2 | 사내 데이터에서 **상용 대비 우위** |
